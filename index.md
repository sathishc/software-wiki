# software-wiki

A LLM-maintained [Karpathy LLM-wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)
for **Software Engineering** — code quality, architecture, testing, and delivery.
Sibling of [`sat-wiki`](../sat-wiki/README.md). Compiled from canonical
sources; cross-referenced so knowledge compounds.

## Pages (Maps of Content)

Navigational synthesis pages — each one a curated map of a domain, not a reference page.

- [Code Quality](pages/code-quality.md) — How code stays readable and changeable — KISS/YAGNI, SOLID, clean code, refactoring, technical debt. Tags: `moc`, `code-quality`, `craftsmanship`
- [Testing & Quality](pages/testing.md) — The safety net that makes everything else possible — unit tests, TDD, the test pyramid, run by CI. Tags: `moc`, `testing`, `tdd`, `quality`
- [Architecture & Design](pages/architecture.md) — How a system is structured — DDD's lens, bounded contexts, monolith vs microservices, API design. Tags: `moc`, `architecture`
- [Delivery](pages/delivery.md) — How software ships and tells you what's happening — CI/CD, DORA metrics, observability, code review. Tags: `moc`, `delivery`
